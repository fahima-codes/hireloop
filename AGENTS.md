# AGENTS.md

## Commands

npm only (package-lock.json, no lockfile for other managers).

- Dev server: `npm run dev` (Turbopack, http://localhost:3000)
- Build: `npm run build`
- Lint: `npm run lint` (flat ESLint config in `eslint.config.mjs`)
- Typecheck: `npx tsc --noEmit` — there is no test or typecheck script; the project has no test setup. Don't invent test commands.

## This Next.js is newer than your training data

Next 16.4.5 + React 19.3. Before writing any Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (starting at `index.md`) — APIs, conventions, and file layout may differ from what you know, and deprecation notices there are authoritative.

`next.config.ts` enables `cacheComponents` and `partialPrefetching`, so caching/rendering defaults differ from a stock setup — check the docs in that package for their exact semantics.

## Layout

- App Router, App-Root dirs (`app/`, `components/`, `lib/`) live at the repo root — there is no `src/`. Path alias `@/*` maps to the repo root.
- Tailwind v4, CSS-first: all theme config lives in `app/globals.css`; there is no `tailwind.config` file. CSS goes through the `@tailwindcss/turbopack` rule in `next.config.ts`.

## UI: shadcn on Base UI, not Radix

- `components.json` uses style `base-nova` — primitives are `@base-ui/react`, and generated imports differ from default (Radix-based) shadcn output. Read `components/ui/button.tsx` as the pattern.
- Add further components with `npx shadcn@latest add <component>`; don't hand-write new ones under `components/ui/`.
- Note: generated components import `cn` from the `cn` npm package, not `@/lib/utils`, despite what `components.json` aliases suggest.

## Gotchas

- `better-auth` is installed but completely unwired (no auth code, no env files tracked). Don't assume login flows or env vars exist.
- `hireloop/hireloop/` is an abandoned, bare `create-next-app` scaffold (its own package.json/lockfile/AGENTS.md, no app code). Ignore it and never edit it; it is inside the root tsconfig's `**/*.ts` include glob, so typecheck may touch it.
- The `nextjs-agent-rules` blocks in `hireloop/hireloop/AGENTS.md` and `node_modules/next/AGENTS.md` are auto-generated by `next dev` — don't treat them as hand-written docs.
